# АБС-Автосервис — первый экран и запись

Статический прототип без сборки и внешних runtime-зависимостей.

## Запуск

```bash
python3 -m http.server 4387 --bind 127.0.0.1
# открыть http://127.0.0.1:4387/
```

Выбор ситуации, форма, чат и все состояния доступны в превью. Для реальной отправки страница должна работать в контуре, где `/api/abs/v1/lead` и `/api/abs/v1/chat` проксируются в существующий API. Без API интерфейс показывает честную ошибку и не имитирует принятую заявку.

## Файлы

- `index.html` — семантика, hero, ситуации, форма, существующий чат.
- `styles/tokens.css` — единственный источник цветов, типографики, spacing и motion.
- `styles/main.css` — адаптив и состояния.
- `app.js` — выбор, локальные события, заявка и мобильная панель.
- `chat.js` — существующий серверный чат без изменений; загружается по первому клику.
- `design/` — commit sheet и shipped design contract.
- `qa/` — кадры и проверки.

Прототип помечен `noindex`. Перед публикацией нужны подтверждённые прайс/правила, юридические тексты, домен/HTTPS и проверка живого API.
